# BattleMath:04 — code:CAT-WARS 設計ノート

kurarowa1（にゃんこ大戦争風・拠点建設＋襲撃バトル）を battlemath04（小4算数の学習ゲーム）に
融合・統合・最適化した際の設計判断を記録する。問題・解答方法は battlemath04 のものを踏襲し、
そこで稼いだ報酬で拠点を築き、ネコ軍団で相手拠点を襲撃する。

## 1. 残したもの / 削ったもの

| 区分 | 内容 |
|---|---|
| 残す | 練習・スピード・復習・本番テスト・きろく、バッジ／背景／称号／学校対抗／管理画面（すべて無変更） |
| 削る | カードバトル導線（`deck_building`/`in_game`）とカードパックショップ（`card_shop`）をメニューから撤去 |
| 追加 | `catwars` モード（拠点建設＋ネコ軍団の襲撃バトル）を新設 |

カードバトルの実装コードはリポジトリに残置し、メニュー導線とルーティングだけを断った（低リスク・
将来の再利用可能）。アイテムショップ（称号／ブースター）は学習のゲーミフィケーションとして維持。

## 2. ポイント／通貨設計（best practice）

**「1通貨に全役割を負わせない」** という原則に基づき、役割の異なる3層＋部隊XPで構成した。
これにより、インフレ・死蔵・動機の単調化を避け、学習量が確実に戦力へ変換される手応えを作る。

| 通貨 | 役割 | 入手 | 用途 | 性質 |
|---|---|---|---|---|
| 💰 ゴールド | ソフト通貨（フロー） | 問題に正解するたび +12／戦闘勝利の戦利品／金山のパッシブ収入 | 拠点の建設・強化、戦闘中のネコ出撃コスト | 潤沢。コアループを回す |
| ⭐ デイリースター | 当日限定通貨 | 正解ごと +1／ログインボーナス | 出撃バフ（小→中→大）、作戦立案での防衛施設配置 | 当日リセット。日々の学習を促す |
| 🌟 スーパースター | ハード通貨（プレステージ） | 正解時にまれにドロップ（3%で+2/7%で+1）／ログイン連続 | レアな宇宙ネコ系統の解放 | 希少。長期目標 |
| 部隊XP | ネコ個別の成長 | 学習で薄く（スターター各+4）／戦闘で厚く（勝35・負15） | レベル→進化（Lv10/Lv30で姿が変化・ステータス倍加） | 「たくさん学ぶ＝ネコが強くなる」教育的フック |

### 既存 MP（mathPoints）との関係
既存の MP システムは**温存**した。MP はバッジ／背景解放／称号／既存アイテムショップの原資として
そのまま機能する。CAT-WARS の3通貨は MP とは独立に、正解報酬イベントへ**加算的にフック**した
（`catwars/bridge.ts`）。これにより後戻り可能・低リスクで、既存の学習体験を一切壊さない。

### 実装の要点（単一シンク）
全モード共通の解答記録 `services/weaknessAnalysisService.recordAttempt()` に
`grantStudyReward()` を1か所だけフックした。練習・スピード・復習のすべての正解が、
自動的に 💰/⭐/🌟/XP に変換される（重複計上なし）。本番テストは現状フック外（将来 `grantBulkReward`
で完了時付与を予定）。

## 3. 拠点・管理構造

- **拠点（BaseBuilder）**: 15×15 グリッド。💰 で施設を建設。施設は戦闘の能力（loadout）を解放する：
  兵舎→アーチャー、大砲／テスラ→防衛設備の持ち込み、アーミーキャンプ→防衛スロット＋出撃範囲、
  壁→持ち込み枚数、金山→パッシブ収入。撤去は半額返金。
- **作戦立案（BattleSetupScreen）**: マップ選択＋緑ゾーンにコア（🏰）と防衛施設を ⭐ で配置。
- **襲撃バトル（BattleScene）**: リアルタイム。💰 でネコを何度でも出撃、経路探索・ターゲッティング・
  呪文・敵ウェーブ・一時ランクアップ。敵コア破壊で勝利、戦利品 💰 と部隊XP を獲得。
- **管理画面**: 既存の GameMaster／単元ロック／学習分析／弱点分析を維持。CAT-WARS 固有の管理
  （敵拠点プリセット・報酬レート）は将来 `config/` に集約し、Firebase で1リード同期する設計余地を残す。

## 4. バックエンド（後日 Firebase）

現状は**オフラインファースト**（zustand persist / localStorage）。kurarowa1 の Supabase 同期は
`catwars/utils/syncToSupabase.ts` を no-op スタブに置換して除去済み。Firebase 実装時は、この
スタブを差し替えるだけで各ストア（player/progress/army）のクラウド同期を有効化できる。
無料枠に配慮し、「起動時1リード・区切りで1ライト（merge）」の粒度を維持する方針。

## 5. UI／デザイン

- タイトルを **BattleMath:04**＋サブタイトル **code:CAT-WARS**（青⇄白⇄赤グラデーション）に刷新。
- 全画面の基調を、青と赤が絶えず入れかわる**動的グラデーション背景**（`components/CyberGradientBG.tsx`、
  CSSアニメーションのみ・`prefers-reduced-motion` 対応）に置換。
- CAT-WARS ハブは 💰⭐🌟🔥 の常時HUD、デイリー目標バー、大きな行動ボタン、拠点ミニプレビューで
  操作導線を明快化。作戦立案・対戦画面はネオン枠・スプライト・ダメージ演出でリッチ化した既存構造を踏襲。
