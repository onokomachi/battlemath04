# VS-No.【syo4】(バーサスナンバー) — 小4算数 まるごと学習ゲーム

小学4年生の算数**全14単元**(学習指導要領・東京書籍『新編 新しい算数 4上・4下』準拠)を、
ゲームを通して網羅的に学習できるWebアプリです。

**収録単元**: 大きい数のしくみ / 折れ線グラフと表 / わり算の筆算(÷1けた・÷2けた) / 角の大きさ /
小数のしくみ / がい数 / 計算のきまり / 面積 / 小数のかけ算とわり算 / 分数 / 変わり方調べ /
直方体と立方体(位置の表し方) / 倍の見方 — **14ワールド・96サブトピック・706問**。
わり算筆算・がい数・小数・倍の見方は参照リポジトリ
(wari-hissann3 / syo4-gaisu / syo4-syousu / syo4-bainomikata)の問題項目を移植しています。

設計はエビデンスに基づいています(数直線を中心的表現とする WWC 分数実践ガイド、精緻化フィードバック、
誤答例からの学習、足場のフェーディング等)。詳細な設計根拠・エビデンスレベル・例題は **[docs/DESIGN.md](docs/DESIGN.md)** を参照してください。

## モード

| モード | 内容 |
|---|---|
| ⚔ カードバトル | 問題カードでCPU・友だちと対戦(HP制。正解でダメージ)。かせいだMPでカードパックを購入 |
| ⚡ スピードデュエル | デッキ不要の早押し勝負(CPU/PvP) |
| 🗺 ワールドマップ(練習) | 14単元=14ワールド。進捗バー・クリア🚩/マスター👑バッジ・先生による開放制御 |
| 🔁 復習モード | まちがえた問題を間隔反復(SRS)で最適なタイミングに再出題 |
| 📝 本番テスト | 新学社まとめテスト形式の**8セット**(大きい数/グラフと表/わり算の筆算/がい数/小数/分数/1学期まとめ/前期まとめ)。表=知識・技能100点/裏=思考・判断・表現50点、大問別の得点と全設問の詳細を記録 |
| 📒 がくしゅうのきろく | きょうやった問題の即時確認・デイリー目標リング・サブトピック別習熟バー・バッジ・テスト履歴 |

### Firebase(オンライン機能)の設定

Firebase未設定でも**オフラインモード(端末内保存)で全学習機能が動作**します。
ログイン・PvP・端末をまたぐ記録同期・先生向け機能を使う場合のみ設定してください。

1. [Firebase Console](https://console.firebase.google.com/) で新しいプロジェクトを作成
2. **Authentication** → ログイン方法で「Google」を有効化
3. **Firestore Database** → データベースを作成(本番モード)
4. プロジェクトの設定 → ウェブアプリを追加 → 表示された設定値を `.env.example` を参考に `.env.local` へ記入
5. `firestore.rules` をコンソールのルールにコピー、`firestore.indexes.json` のインデックスを作成

```bash
cp .env.example .env.local
# VITE_FIREBASE_* を記入
```

学校名は `VITE_SCHOOL_NAME` で設定します(ログインは自校のみの簡易方式: 組と出席番号を選ぶだけ)。

## 技術構成

- React 19 + TypeScript + Vite + Tailwind CSS
- Zustand(進捗・ゲーミフィケーション状態)
- Firebase Authentication / Cloud Firestore(任意・環境変数で注入)
- 問題データは決定的に生成(乱数なし)— PvPで全クライアントのカード定義が一致
- わり算のあまりは「24あまり3」形式、大きい数は「180億」と「18000000000」の両表記を正答、小数は数値比較(1.60=1.6)で採点

## 開発メモ

- 採点は `utils/answerChecker.ts` に一本化。分数は `utils/fraction.ts` が
  「値+分母の両立」で判定(帯分数⇔仮分数の等値表現を許容、約分形は4年未習のため不可、
  変換問題は `requireForm` で解答形式を固定)
- 分数の表示は `components/FractionText.tsx`(積み上げ表記)。問題文は `{3/4}` `{2と1/3}` マークアップ
- 数直線・リットルます・テープ図は `utils/fractionSvg.ts` が決定的SVGとして生成
- `reference/` は参照専用資料(Git・ビルド対象外)

## 先生向け機能(管理画面)

- **単元ロック**: `config/unit_locks` にロックする単元名を保存。まだ学習していない単元のカード・練習・ショップ・スピードデュエルを児童側で使用不可にできる(読み1回/起動・書き1回/保存)
- **学習分析**: 児童側は端末内に日次集計し、セッション終了時に `dailySummaries/{uid_日付}` へ 1回の setDoc(merge) のみ。管理画面は選んだ日付の1クエリで、取り組み・正答率・誤答の多いサブトピック・児童別の単元内訳を表示(150人×毎日でも無料枠に収まる設計)
- **個別ランキングは児童側に表示しない**(比較による動機低下を避け、自分の進捗・バッジ・背景で動機づけ)
